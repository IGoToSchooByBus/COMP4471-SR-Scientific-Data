# 03 · 進一步方向

按「價值 / 成本」排序，標 ✅ 的已實作。

## 方向 A：工程化（✅ 已完成）

| 項目 | 目的 |
|---|---|
| seed 可復現 | 每次跑結果一致，才能做消融 |
| 真殘差學習 `pred = bicubic + model(...)` | 收斂快、好訓練 |
| 歸一化 | 梯度健康、防洩漏 |
| validation + 早停 | 防過擬合、知道何時停 |
| checkpoint 存檔 + resume/eval_only | 不丟結果、可續練、可只評估 |

## 方向 B：讓任務更有鑑別力（✅ 已完成）

| 項目 | 目的 |
|---|---|
| pointwise 下採樣（無反鋸齒） | 製造 aliasing，凸顯深度學習 |
| L1 / 梯度損失（Sobel） | 保留銳邊、降 MaxError |
| 多倍率 ×2/×4/×8 | `--factor` 支援 |

## 方向 C：加網路（✅ 已完成）

| 項目 | 狀態 |
