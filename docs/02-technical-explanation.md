# 02 · 技術解釋

## 1. 整體流程

```
HR 真值 (128×128×C)   C = 通道數（1 或 3，自動偵測）
   │  下採樣（縮小）
   ▼
LR 輸入 (32×32×C)
   │  ① bicubic 放大回 128×128
   │  ② U-Net 預測「殘差」
   │  ③ 相加：pred = bicubic(LR) + U-Net(bicubic(LR))
   ▼
預測 (128×128×C)
```

## 2. 資料與下採樣

### 原始資料
HDF5 檔 `2D_rdb_NA_NA_.h5`，每個樣本存 `data`（shape `[21, 128, 128, 3]`，通道 `h/u/v`）與 `grid/x`、`grid/y`、`grid/t`。用 21 幀（t=0~100 每 5 步存一幀）做多時間步訓練。

### 兩種下採樣
| 方法 | 做法 | 特性 |
|---|---|---|
| **block-average** | 4×4 取平均（=平均池化） | 反鋸齒低通，LR「乾淨」，bicubic 好補 |
| **pointwise** | `hr[::f, ::f]` 隔行取樣 | 無反鋸齒 → **aliasing 鋸齒**，bicubic 補不好，但深度學習能補 |

**關鍵**：block-average 把高頻「濾掉」，難題被移除；pointwise 讓高頻「折疊」成鋸齒，還原難度大增 → 凸顯深度學習的價值。

## 3. U-Net 架構（MiniUNet）

2 層 encoder–decoder，`base=32`，通道數自動偵測（1 或 3）。`H×W×C` = 高×寬×通道。另有 SRCNN、UNet2d、UNet2d-wide 可選（`--model`）。

```text
          輸入 LR_up（bicubic 放大後）
              128 × 128 × C
                    │
        ┌───────────▼───────────┐
        │  enc1                 │   Conv3×3 (C → 32) + ReLU
        │  編碼器第 1 層         │   Conv3×3 (32 → 32) + ReLU
        └───────────┬───────────┘
                    │  e1 = 128×128×32 ──────────────┐
        ┌───────────▼───────────┐                     │  ← skip 連接
        │  MaxPool 2×2          │                     │    （把 e1 複製到右邊）
        └───────────┬───────────┘                     │
                    │  64×64×32                       │
        ┌───────────▼───────────┐                     │
        │  enc2                 │   Conv3×3 (32 → 64) │
        │  編碼器第 2 層         │   Conv3×3 (64 → 64) │
        └───────────┬───────────┘                     │
                    │  e2 = 64×64×64  (bottleneck)    │
        ┌───────────▼───────────┐                     │
        │  ConvTranspose2d      │   64→32, k=2×2, s=2 │
        └───────────┬───────────┘                     │
                    │  128×128×32                     │
                    ▼                                 ▼
                 concat  ←──────────（接回 e1）────────┘
                    │  128×128×64 (32+32)
        ┌───────────▼───────────┐
        │  dec2                 │   Conv3×3 (64 → 32) + ReLU
        │  解碼器                │   Conv3×3 (32 → 32) + ReLU
        └───────────┬───────────┘
                    │  128×128×32
        ┌───────────▼───────────┐
        │  out                  │   Conv1×1 (32 → C)
        └───────────┬───────────┘
                    │
          殘差輸出 128 × 128 × C
```

**三大件**：
- **Encoder（收縮）**：下採樣 + 通道增加，抽取抽象特徵。
- **Bottleneck**：空間最小、感受野最大。
- **Decoder（擴張）**：上採樣還原解析度。

**skip connection（靈魂）**：把 encoder 高解析度細節直接送到 decoder。下採樣會丟失細節（尤其銳利邊緣的位置），skip 連接讓模型能精確重建衝擊波。

### 殘差學習
`pred = bicubic(LR) + model(bicubic(LR))`。bicubic 已接近答案，模型只學「小修正量」→ 收斂更快、更穩。

## 4. 歸一化

用**訓練集**的 `mean/std` 把 LR、HR 一起標準化，評估時 denormalize。理由：
- 水位有大 DC 偏移（h 通道 mean≈0.117），歸一化後梯度更健康。
- 只從訓練集算 → 防洩漏。
- block-average 是線性運算，LR/HR 用同一統計量自洽。

## 5. 損失函式

| 損失 | 公式 | 特性 |
|---|---|---|
| MSE (L2) | `mean((pred−hr)²)` | 最優解是條件平均 `E[HR|LR]` → 傾向模糊 |
| L1 (MAE) | `mean(|pred−hr|)` | 最優解是中位數 → 保留銳邊 |
| Charbonnier | `mean(√((pred−hr)²+ε²))` | L1 的平滑版 |

### 梯度損失（gradient loss）
用 Sobel 算子算「邊緣圖」，逼預測的邊緣 ≈ 真值的邊緣：

```python
def sobel(x):            # Sobel 邊緣算子（偵測梯度幅值）
    kx = [[-1,0,1],[-2,0,2],[-1,0,1]]   # 偵測垂直邊
    ky = kx 的轉置                        # 偵測水平邊
    return sqrt(conv(x,kx)² + conv(x,ky)²)

gradient_loss = MSE(sobel(pred), sobel(hr)) / (sobel(hr)² 的均值)   # 歸一化
loss = 主損失 + λ * gradient_loss
```

- **Sobel**：離散微分算子，同時做「差分 + 平滑」，比簡單 `[-1,1]` 抗噪。
- **為什麼要梯度損失**：MSE 的條件平均會把銳邊抹糊；梯度損失直接懲罰「邊緣不一致」，銳化衝擊波。
- **歸一化**：避免梯度損失的數值遠大於像素損失（否則 λ 難調）。

## 6. 優化器與 backprop

- **Backprop**（`loss.backward()`）：用 chain rule 算「損失對權重的梯度」`∂L/∂W`。
- **Adam**（`optimizer.step()`）：用梯度更新權重的優化器，結合 momentum + 自適應學習率。
- **ReduceLROnPlateau**：驗證停滯時 lr 減半。
- **Early stopping**：連續 `patience` 個 epoch 驗證無改善即停。

> 澄清：「梯度」有兩個意思——backprop 的梯度是 `∂L/∂W`（更新權重用）；gradient loss 的梯度是影像空間梯度 `∇f`（描述邊緣）。兩者不同。

## 7. 評估指標

| 指標 | 意義 |
|---|---|
| MSE | 逐像素平方誤差平均 |
| PSNR | `10·log10(data_range² / MSE)`，越高越好 |
| SSIM | 結構相似度（0~1） |
| MAE | 平均絕對誤差 |
| **MaxError** | 每張圖最大誤差（反映衝擊波處的最糟還原） |

## 8. 關鍵概念

- **`E[HR|LR]`**：條件期望 = 「給定 LR，所有可能 HR 的平均」。MSE 的最優解就是它，這是 MSE 會模糊的數學根源。
- **bias-variance**：更多資料 → 降低 variance（過擬合）；本資料是「2 參數家族」（dam_radius × inner_height），1000 場已覆蓋得很密，加樣本數邊際效益遞減，應改加「多樣性」（如其他 PDE）。
