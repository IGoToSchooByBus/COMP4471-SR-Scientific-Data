# 01 · Project 目標

## 問題定義

科學模擬（流體、天氣、地震等）會產生**高解析度的二維物理場**，儲存、傳輸、視覺化都很昂貴。

本專案研究：**能否用深度學習，從低解析度輸入重建出高解析度的科學模擬資料**。

- 這是「超解析度（Super-Resolution, SR）」任務，但對象是**物理場**，不是自然影像。
- 本質是 **ill-posed 反問題**：下採樣丟掉資訊，同一個 LR 可能對應多個 HR，模型必須在訓練中學到「精細尺度的結構」。

## 目標

1. 建立可復現的 SR 訓練/評估流程。
2. 用多個 baseline（bicubic、1-NN、線性內插、LR 最近鄰）嚴格檢驗深度學習（U-Net 家族）是否真的「學到東西」。
3. 探討不同設計的影響：下採樣方式、損失函式、模型容量、量測雜訊、外推（參數/時間）。
4. 用定量（PSNR/SSIM/MSE/MAE/MaxError，含分通道）與定性（誤差圖）方式評估。

## 資料：PDEBench 2D 淺水波（radial dam break）

| 項目 | 值 |
|---|---|
| 來源 | PDEBench benchmark（NeurIPS 2022） |
| 物理 | 淺水波方程，圓形潰壩模擬 |
| 樣本數 | **1000（每場唯一，2 參數不同）**，train 900 / test 100（隨機切分） |
| 空間解析度 | 128 × 128 |
| 時間步 | **21 幀**（t=0~100 每 5 步存一幀，多時間步訓練） |
| 通道 | **3（水位 `h`、流速 `u`、`v`）** |
| 變異來源 | **2 參數：`dam_radius ∈ [0.3, 0.7]` × `inner_height ∈ [1.5, 2.5]`** |
| 數值方法 | Clawpack/PyClaw，有限體積法（FVM） |

**物理結構**：潰壩後形成一圈向外傳播的**衝擊波（shock front）**——這是場裡最銳利、最難還原的結構，也是本專案的核心難點。

## 方法總覽

```
HR 真值 (128×128×3)
   │  下採樣（block-average 或 pointwise）
   ▼
LR 輸入 (32×32×3)
   │  bicubic 放大 + 模型殘差修正
   ▼
預測 (128×128×3)
```

- **模型**：SRCNN、MiniUNet、UNet2d、UNet2d-wide（`--model` 選擇）。
- **Baseline**：bicubic；oracle（1-NN / 線性內插，用真值參數查表）；LR 最近鄰（非參數，看噪聲 LR）。
- **損失**：L1 + 梯度損失（Sobel）。
- **優化**：Adam + ReduceLROnPlateau + 早停。
- **指標**：MSE、PSNR（分通道）、SSIM、MAE、MaxError。

## 主要結論（詳見 [04-progress](./04-progress.md)）

1. U-Net（57.43 dB）大幅超越 bicubic（37.13 dB），但**未超越「參數空間線性內插」oracle（57.92 dB）**。
2. 噪聲下 LR 最近鄰勝過所有 U-Net，顯示非參數查表在此平滑資料的抗噪優勢。
3. 噪聲下模型容量排序反轉（大模型在 σ>0 反超）。
4. 共同指向：此資料（2 參數、平滑）對深度學習過於簡單，需湍流等更高複雜度的場才能彰顯 SR 價值。
